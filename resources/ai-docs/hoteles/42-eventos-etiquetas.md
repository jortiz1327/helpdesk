# Eventos: Etiquetas

## Para qué sirve
Reservar etiquetas electrónicas (ESL) para uso exclusivo de eventos y ver cuáles están libres o en un kit.

## Quién lo usa y dónde está
Menú **Eventos > Etiquetas**. Añadir etiquetas requiere el permiso `add-event-pricetags` (antes solo lo podía hacer el superadmin).

## Cómo se hace (paso a paso)
1. Pulsar "Añadir etiquetas".
2. Escribir la **MAC** de cada etiqueta; "Añadir más" permite varias.
3. Pulsar Añadir. Cada una se vincula al cloud y se marca para eventos.
4. Resultado: éxito total, parcial (":added añadidas, :failed no se pudieron añadir") o error si ninguna se pudo.

## Problemas frecuentes y cómo resolverlos
- **"None of the pricetags could be added"**: ninguna MAC válida o el cloud la rechaza; revisar la MAC.
- **Algunas fallan**: se muestran con su motivo; reintentar solo esas.
- **No veo el botón**: falta el permiso.

## Preguntas típicas de clientes
- ¿Dónde leo la MAC? En la etiqueta física.
- ¿Puedo añadir varias a la vez? Sí.
- ¿Una etiqueta de eventos sirve en la carta normal? No, quedan reservadas.
- ¿Cómo la libero? A confirmar si hay opción de quitarla desde esta pantalla.
- ¿Qué tamaños hay? Los de la etiqueta; las grandes (11.6 y 13.3 pulgadas) se tratan distinto ([Kits](42-eventos-kits.md)).
