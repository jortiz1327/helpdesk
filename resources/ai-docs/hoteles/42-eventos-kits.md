# Eventos: Kits

## Para qué sirve
Un kit es un conjunto de etiquetas de eventos con sus posiciones. Es la pieza reutilizable que se mete en los menús de evento.

## Quién lo usa y dónde está
Menú **Eventos > Kits**.

## Cómo se hace (paso a paso)
1. Pulsar "Crear nuevo kit".
2. Poner el **Nombre del kit**.
3. Elegir las etiquetas (por tamaño, "Etiquetas disponibles"). Se muestra la lista de posiciones que se crearán; se puede cambiar el prefijo.
4. Crear. Las posiciones se vinculan en el cloud.
5. En las etiquetas grandes (11.6 y 13.3 pulgadas) se elige la opción: leyenda de alérgenos o menú.
6. Para borrar: confirmar "¿Estás seguro de que quieres eliminar este kit?".

## Problemas frecuentes y cómo resolverlos
- **Ya existe un kit con ese nombre**: usar otro nombre.
- **"Select at least one pricetag"**: elegir al menos una.
- **"A position with that name already exists. Try changing the prefix"**: cambiar el prefijo.
- **La etiqueta no tiene plantilla de N platos**: genera las plantillas o usa una etiqueta compatible.

## Preguntas típicas de clientes
- ¿Cuántos platos por etiqueta? Depende del modelo y su plantilla.
- ¿Un kit puede estar en dos menús? No.
- ¿Puedo cambiar la opción de una etiqueta grande? Sí, desde el menú del evento.
- ¿Qué pasa al borrar un kit? Se desvinculan sus etiquetas.
- ¿Puedo editar un kit? Solo se cambia la opción por posición; para otro cambio, recrearlo (a confirmar).
